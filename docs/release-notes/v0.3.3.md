# v0.3.3 — Your plans keep their own names

## Fixed

- Editing an Activity no longer replaces custom titles on its linked planned blocks.
- A block with no custom title may display its linked Activity name without saving that fallback into the block.
- Updating linked planned blocks preserves each block's own title.

## Improved

- Manage Activities now includes live color preview, direct HEX entry, curated presets, and a full custom color picker.
- HEX colors accept `#RRGGBB` and `#RGB` (with or without `#`) and save in uppercase `#RRGGBB` form. Invalid values are blocked with inline guidance.
- Activity color normalization now covers local migration, restored state, and cloud serialization/deserialization.
- Calendar text on Activity-colored tracked and live entries uses a readable black or white foreground.
